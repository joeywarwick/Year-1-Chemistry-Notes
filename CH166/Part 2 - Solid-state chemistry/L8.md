## 2. Unit cells
- Crystals are solid structures with repeating units.
	- These repeating unis are known as **unit cells**.
- Unit cells are the **smallest** **parallel-sided** unit from which a crystal can be built using only **translational displacements**.
> As in no rotations permitted.
### 2.1. 2D unit cells
- Because of this, unit cells can only be certain shapes:
		- Square;
		- Rhomboid;
		- Hexagon;
- Take the following 2D crystal:

| X   | O   | X   | O   |
| --- | --- | --- | --- |
| O   | X   | O   | X   |
| X   | O   | X   | O   |
| O   | X   | O   | X   |
- One of the possible unit cells are:

| X   | O   | X   |
| --- | --- | --- |
| O   | X   | O   |
| X   | O   | X   |
- But this is not the smallest (Area = 9)
- This is instead:

|     | O   |     |
| --- | --- | --- |
| O   | X   | O   |
|     | O   |     |

- This unit cell has area 2. 
	- So this is the **preferred** unit cell.
> **NOTE** Triangles cannot be the unit cell - to fully cover they require **rotation**.
### 2.2. 3D unit cells
- If the 3D unit cell was repeated to form a larger structure, the structure is called **crystal lattice**.
- The atoms in a unit cell are known as **lattice points**.
	- It is important because it is where X-ray diffraction (XRD) focuses on.
- Cubic is the most common type of unit cells:
	- They are also very simple geometrically.
- Vectors are used to describe the translations between lattice points.
- There are three types of cubic unit cells:
	- Simple cubic, where the atoms are situated on the corner of the unit cell.
	- Body-centred cubic, which is a simple cubic with an extra atom in the centre.
	- Face-centred cubic, which is a simple cubic plus a atom on each face.
> The length of a cubic unit cell is defined as 1.
- So they can be described as having different permutations.
#### 2.2.1. Simple cubic cells
- For a lattice point in a simple cubic unit cell:
	- It has six neighbouring atoms, each with a different vector:
		- 1, 0, 0
		- 0, 1, 0
		- 0, 0, 1
		- -1, 0, 0
		- 0, -1, 0
		- 0, 0, -1
	- So it is described as having **6** permutations.
- It is important to calculate the number of atoms in a unit cell. Take a **simple cubic**:
	- **8 corners** each with one atom.
		- Corners imply 1/8, as the atom is shared between 7 other cells.
	- $Total \space atoms = 8 \times \frac{1}{8} = 1 \space atom$
> Because we know the number of atoms in a cell, we can calculate the mass and consequently the density of the cell.

> Only polonium is simple cubic, because simple cubic is not very effective for packing atoms.
