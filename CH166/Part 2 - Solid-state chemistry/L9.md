## 2. Atomic coordinates and projections
- The 3D representation is good visually, but difficult for counting atoms.
	- A **projection** is used instead to simplify the process.
- A projection can be made by viewing the crystal unit cell from **one of the faces**.
	- So only the **vertical coordinate** from the face would need to be considered.
- Consider a **BCC unit cell** with the same corner atom and a different central atom (See L7):
	- When viewed from the **top** the face looks like the following:

| O   |     | O   |
| --- | --- | --- |
|     | X   |     |
| O   |     | O   |
- To indicate the presence of atoms on top of each other, their vertical coordinates, or depth, is used:

| O (0,1) |                     | O (0,1) |
| ------- | ------------------- | ------- |
|         | X ( $\frac{1}{2}$ ) |         |
| O (0,1) |                     | O (0,1) |
> The 0 indicates that the atom is on the surface, the 1 indicates that the atom is at the opposite surface.
- This is a projection of the BCC unit cell described above.

## 3. Atom packing
- Atoms generally want to be packed as **closely and efficiently** as possible.
### 3.1. Close packing of atoms
- So they will pack in rows of atoms displaced by **half of an atom, forming a layer (Layer A) of atoms.
- The second layer (Layer B) would sit in the 'pits' formed from the previous layer
- The third layer will again sit in the 'pits' formed by layer 2, but this can be done in two ways:
	- C can have has the **same configuration as layer A**, resulting in an ABA repetition pattern; or
	- Displace by another 1/2 atom, resulting in an ABC repetition pattern.
- ABA packs hexagonally to give a **hexagonal** unit cell. This is known as the **hexagonal close-packed** configuration.
- ABC gives a **FCC unit cell** when rotated 45 degrees. 
### 3.2. Non-close packing of atoms
- Sometimes atoms will pack in squares.
	- This gives a larger 'pit' than close packing, so less efficent.
- After the first layer, the second layer can add in two ways:
	- Directly on top, with no displacement (AAA) packing pattern.
		- This yields a **simple cubic** unit cell.
	- In the 'pits', with some displacement (ABA).
		- This yields a **BCC** unit cell.
> **AAA has the lowest efficiency**, so **very few crystals will take this structure.**
### 3.3. Atomic packing factor
- To measure the efficiency of packing, we can calculate the atomic packing factor (APF) of a cell, which is the fraction of the unit cell being taken up by atoms.
#### 3.3.1. APF for BCC
- Consider a BCC cell:
	- We first define the volume of the unit cell as a<sup>3</sup>.
	- We also know that the volume of an atom is $\frac{4}{3}\pi r^3$
		- 2 atoms in a BCC, so $\frac{8}{3}\pi r^2$
	- The distance between opposite corners of the cell is $a\sqrt{3}$
		- This is the length of 4 radii of the atom.
			- $a\sqrt{3} = 4r$
				- $\frac{1}{4}a\sqrt{3} = r$
	- We can calculate the volume of atoms in the molecule using this fact:
		- $V_{atoms} =\frac{8}{3}\pi(\frac{1}{4}a\sqrt{3})^3 =  \frac{\sqrt{3}}{8}\pi a^3$ 
		- So $APF_{BCC} \approx 0.68$
#### 3.3.2. APF for FCC
- Consider a FCC cell:
	- Considering a face of the cube:
		- Length of diagonal = $a\sqrt{2}$
			- $r = \frac{1}{4}a\sqrt{2}$
	- Total atom volume = $4[\frac{4}{3}\pi(\frac{1}{4}a\sqrt{2})^3] = \frac{16}{3}\pi(\frac{2\sqrt{2}}{64}a^3)$
		- 73%
