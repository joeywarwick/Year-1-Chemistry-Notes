## 2. LCAOs for polyatomic molecules
- LCAOs can be used to justify a range of experimental observations
	- VSEPR predictions of shapes;
	- Presence of two different MOs in methane;
	- Hypervalency.
### 2.1. SALCs of BeH<sub>2</sub>
- We know that BeH<sub>2</sub> has a **linear geometry.**
- Evaluating the 1s orbitals of the two hydrogens,
	- There is **symmetric SALC**, where both 1s have the **same phase;**
	- And **asymmetric SALC**, where the two 1s have **different phases**
- Be has four frontier AOs:
	- 2s
	- 2p<sub>x</sub>
	- 2p<sub>y</sub>
	- 2p<sub>z</sub>
- We know that **net-zero overlap** results in a **symmetry forbidden** interaction.
- For symmetric SALC,
	- Only 2s is able to interact with it.
- For asymmetric,
	- Only 2p<sub>z</sub> is able to interact with it.
- The other orbitals are therefore non-bonding.
- From this we can construct the MOELD

| AO<sub>2H</sub> | SALCs         | AO<sub>Be</sub> | BeH<sub>2</sub> | Electron 1 | Electron 2 |
| --------------- | ------------- | --------------- | --------------- | ---------- | ---------- |
| 1s              | σ<sub>u</sub> | 2p<sub>z</sub>  | 2σ<sub>u</sub>* |            |            |
| 1s              | σ<sub>g</sub> | 2s              | 2σ<sub>g</sub>* |            |            |
|                 |               | 2p<sub>x</sub>  | 1π<sub>u</sub>  |            |            |
|                 |               | 2p<sub>y</sub>  | 1π<sub>u</sub>  |            |            |
| 1s              | σ<sub>u</sub> | 2p<sub>z</sub>  | 1σ<sub>u</sub>  | ✓          | ✓          |
| 1s              | σ<sub>g</sub> | 2s              | 1σ<sub>g</sub>  | ✓          | ✓          |
- Bond order 2, HOMO 1σ<sub>u</sub>, LUMO 1π<sub>u</sub>.
> **NOTE** the bond order calculated is 2 for the entire molecule, therefore it is 1 per Be-H bond.
### 2.2. SALCs for Water
- We know that water has a **bent structure.**
- Again, we start by looking at the hydrogen 1s' SALCs
	- Symmetric and asymmetric (see above)
- Looking at O frontier AOs:
	- 2s
	- 2p<sub>x</sub>
	- 2p<sub>y</sub>
	- 2p<sub>z</sub>
- For the symmetric SALC:
	- 2s works,
	- 2p<sub>x</sub> works
	- 2p<sub>y,z</sub> both produce net-zero overlap
- For the asymmetric SALC:
	- Only 2p<sub>z</sub> works
- We can then construct the MOELD in a similar manner:

| AO<sub>2H</sub> | SALCs         | AO<sub>O</sub>     | H<sub>2</sub>O | Electron 1 | Electron 2 |
| --------------- | ------------- | ------------------ | -------------- | ---------- | ---------- |
| 1s              | b<sub>2</sub> | 2p<sub>x</sub>     | 2b<sub>2</sub> |            |            |
| 1s              | a<sub>1</sub> | 2s                 | 3a<sub>1</sub> |            |            |
|                 |               | 2p<sub>y</sub>     | 1b<sub>1</sub> | ✓          | ✓          |
| 1s              | a<sub>1</sub> | 2p<sub>x</sub>, 2s | 2a<sub>1</sub> | ✓          | ✓          |
| 1s              | b<sub>2</sub> | 2p<sub>z</sub>     | 1b<sub>2</sub> | ✓          | ✓          |
| 1s              | a<sub>1</sub> | 2s                 | 1a<sub>1</sub> | ✓          | ✓          |

- From quantum chemical calculations 2a<sub>1</sub> is **weakly bonding.**
- So this gives BO of 3.
	- The BO does not correspond fully to the lines.
- Expected value **would be 2-3**, because 2a<sub>1</sub> is not fully bonding.
### 2.3. Walsh diagrams
- Walsh diagrams show how the energy of MOs change as the shape of a molecule changes.
	- The change is usually the bond angle
- **Generally**, shapes can be predicted by finding the combination of filled MOs that produce the lowest total energy.
- This is stated in **Walsh's rule**: A molecule will adopt the structure that best stabilises the HOMO. If HOMO is not affected by structural change the next occupied MO will govern the geometric preference.
- Take BeH<sub>2</sub> and H<sub>2</sub>O, which are AH<sub>2</sub> molecules:
- For BeH<sub>2</sub>
	- As they move away from 180<sup>o</sup> towards 90, the orbital overlap decreases;
		- So energy of the orbitals begin to increase for 1σ<sub>g</sub>, its HOMO.
		- So these molecules prefer a linear arrangement.
- Water is more complicated:
	- The HOMO of water is 1b<sub>1</sub>
		- It is **not perturbed** by structural changes;
	- The next MO is 2a<sub>1</sub>
	- 2a<sub>1</sub> decreases in energy as the angles moves from 180 degrees to 90 degrees.
	- However, 1a<sub>1</sub> and 2a<sub>1</sub> increase in energy, and 104.5 degree is the balance between all orbitals.
## 3. SALCs of complex molecules
### 3.1. SALCs of methane
- There are two types of hydrogen SALCs in methane.
	- One 'All in phase', or a<sub>1</sub>; and
	- Three 'One nodal plane', or t<sub>2</sub>.
		- t for 'triply degenerate'
- By combining the C frontier orbitals, we can obtain that
	- 2s matches with the all in phase;
	- Each 2p matches with one one nodal plane.
- From this we can construct MOELD again:

| AO<sub>C</sub> | SALC<sub>H</sub> | MO              | Electron 1 | Electron 2 |
| -------------- | ---------------- | --------------- | ---------- | ---------- |
| 2p             | t<sub>2</sub>    | 2t<sub>2</sub>* |            |            |
| 2p             | t<sub>2</sub>    | 2t<sub>2</sub>* |            |            |
| 2p             | t<sub>2</sub>    | 2t<sub>2</sub>* |            |            |
| 2s             | a<sub>1</sub>    | 2a<sub>1</sub>* |            |            |
| 2p             | t<sub>2</sub>    | 1t<sub>2</sub>  | ✓          | ✓          |
| 2p             | t<sub>2</sub>    | 1t<sub>2</sub>  | ✓          | ✓          |
| 2p             | t<sub>2</sub>    | 1t<sub>2</sub>  | ✓          | ✓          |
| 2s             | a<sub>1</sub>    | 1a<sub>1</sub>  | ✓          | ✓          |
- BO = 4, HOMO = 1t<sub>2</sub>, LUMO = 2a<sub>1</sub>*
### 3.2. SALCs of octahedral molecules
- There are six possible SALCs:
	- 1 All in phase (a<sub>1g</sub>);
	- 3 One nodal plane (t<sub>1g</sub>); and
	- 2 Two nodal planes (e<sub>g</sub>).
- Considering SF<sub>6</sub>
	- 3s matches with a<sub>1g</sub>
	- 3ps each matches with one 1<sub>1g</sub>
	- None matches with e<sub>g</sub>
- So we can construct MOELD on this basis

| MO              | Electron 1 | Electron 2 |
| --------------- | ---------- | ---------- |
| 2t<sub>1</sub>* |            |            |
| 2t<sub>1</sub>* |            |            |
| 2t<sub>1</sub>* |            |            |
| 2a<sub>1</sub>* |            |            |
| 1e<sub>g</sub>  | ✓          | ✓          |
| 1e<sub>g</sub>  | ✓          | ✓          |
| 1t<sub>1</sub>  | ✓          | ✓          |
| 1t<sub>1</sub>  | ✓          | ✓          |
| 1t<sub>1</sub>  | ✓          | ✓          |
| 1a<sub>1</sub>  | ✓          | ✓          |
- BO = 4, HOMO = 1e<sub>g</sub>, LUMO = 2a<sub>1</sub>
- So bond order per bond is 0.67
