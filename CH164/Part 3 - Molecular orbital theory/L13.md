## 2. The HAO model
### 2.1. Limitations of LCAOs
- LCAOs become **very complex** for larger molecules without computers.
	-  To construct MOELD for butane, 4 x 4 + 1 x 10 = 26 orbitals' SALCs would need to be considered. 
- We can circumvent this problem with a **model** that breaks molecules into **localised bonding interactions** between **pairs of** atoms.
- **Hybridised of atomic orbitals (HAO) model** can be used to simplify this.
### 2.2. Hybridising AOs
- The HAO model can be applied by mixing AOs on the same atom to form a orthogonal set of HAOs that point towards other atoms.
> **NOTE** This model cannot be used to predict the shape; orbitals hybridise to give the shape.
#### 2.2.1. Types of hybridisation
- There are three main types of hybridisation:

| Shape           | Bond angle | s-orbital | p-orbital | HAO              | Unhybridised AOs | % s-character | % p-character |
| --------------- | ---------- | --------- | --------- | ---------------- | ---------------- | ------------- | ------------- |
| Tetrahedral     | 109.5      | 1         | 3         | 4 sp<sup>3</sup> | 0                | 25            | 75            |
| Trigonal planar | 120        | 1         | 2         | 3 sp<sup>2</sup> | 1 p              | 33            | 67            |
| Linear          | 180        | 1         | 1         | 2 sp             | 2 p              | 50            | 50            |
- Both sp<sup>2</sup> and sp results in left-over p-orbitals.
	- They can be used in π-bonds.
- An **increase in s-character decreases energy and increases the bond angle.** 
### 2.3. HAO model for methane
- We have previously considered methane using LCAOs (see [[CH164/Part 3 - Molecular orbital theory/L12]])
- We can break methane into four C-H bonding interactions.
- In carbon, **the s- and p-orbitals hybridise into sp<sup>3</sup> orbitals.**
- Similarly, there are in-phase and out-of-phase interactions.
- Based on this we can construct the HAO MOELD:

| HAO<sub>C</sub> | CH<sub>4</sub> | AO<sub>H</sub> | Electron 1 | Electron 2 |
| --------------- | -------------- | -------------- | ---------- | ---------- |
| sp<sup>3</sup>  | σ*             | 1s             |            |            |
| sp<sup>3</sup>  | σ*             | 1s             |            |            |
| sp<sup>3</sup>  | σ*             | 1s             |            |            |
| sp<sup>3</sup>  | σ*             | 1s             |            |            |
| sp<sup>3</sup>  | σ              | 1s             | ✓          | ✓          |
| sp<sup>3</sup>  | σ              | 1s             | ✓          | ✓          |
| sp<sup>3</sup>  | σ              | 1s             | ✓          | ✓          |
| sp<sup>3</sup>  | σ              | 1s             | ✓          | ✓          |
- This is simpler because each of these bonds are considered to be identical.
- BO = 4, so BO = 1 per C-H bond.
#### 2.3.1. HAO model for butane
- We can further apply this model onto butane, by considering it as **four C-C bonds and ten C-H bonds.** 
- sp<sup>3</sup>s from the carbon will overlap with each other, as well as the AOs from the hydrogen.
- This would give us 26 MOs to consider, much simpler than LCAO approach.
#### 2.3.2. HAO model for the methyl cation, anion, and radical
- For the cation CH<sub>3</sub><sup>+</sup>, one of the sp<sup>3</sup> becomes vacant, resulting in a trigonal planar geometry.
	- So we give sp<sup>2</sup> hybridisation instead of sp<sup>3</sup>.
- For the anion CH<sub>3</sub><sup>-</sup>, the lone pair after removing the H<sup>+</sup> results in trigonal pyramidal,
	- So the sp<sup>3</sup> is kept. 
- For the radical CH<sub>3</sub><sup>.</sup>, the orbital is singly occupied, but is trigonal planar;
	- So we assign sp<sup>2</sup>.
#### 2.3.3. Hybridisation for other molecules
- Other central atoms such as N, B, O, and Be can all undergo hybridisation.
- Take NH<sub>3</sub> for example:
	- 1 lone pairs, 3 σ bonds. 
	- sp<sup>3</sup>
- Take BeH<sub>2</sub>:
	- 0 lone pairs, 2 σ bonds
	- sp
- Take HCHO:
	- 0 lone pairs, 3 σ bonds, 1 π bond
	- sp<sup>2</sup> (for both C and O)
- Take CO
	- 0 lone pairs,  2 σ bonds, 2 π bonds
	- sp (for both C and O)
### 2.4. Comparing LCAO and HAO approaches
#### 2.4.1. LCAO and HAO for simple polyatomic molecules
> **NOTE** Two different HAO models are required to predict the bond angle.
- Using BeH<sub>2</sub> as example:
	- LCAO tells us that there are **two different types of σ bonds** formed in between the 2p and 1s orbitals.
	- HAO tells us that there are only one, with **doubly degenerate orbitals.**
	- The non-bonding orbitals are, however, in agreement.
- Using water:
	- LCAO tells us that there are **3 bonding** MOs, all at different energies.
	- HAO tells us that there are only **2 degenerate** MOs.
	- Non-bonding orbitals are in agreement.
#### 2.4.2. Ethene and ethyne
- On ethene, the carbons are sp<sup>2</sup> hybridised. This means that the extra p-orbitals can combine to form **a π-bond** between the two carbons.
- On ethyne, the carbons are sp hybridised instead. So the 2 extra p-orbitals can form **two π-bonds** between the carbons.
#### 2.4.3. Methanal
- Looking back at methanal (HCHO):
	- We know that the **bonding** π MO formed between the carbon and oxygen will have more contribution from oxygen, because oxygen's p-orbitals will have lower energy.
		- This is fundamentally electronegativity (See L11)
	- The antibonding, however, will be reversed, with more contribution from carbon compared to oxygen.
#### 2.4.4. Transition metal complexes
- d-orbitals can be involved in hybridisation if their energies are sufficiently low.
- In transition metal (TM) complexes, AOs hybridise to from HAOs that would point at the ligands.
#### 2.4.5. Overall comparison
- Advantages:
	- Simpler and more intuitive
	- Useful for a simple description of localised bonding
	- Useful qualitatively for organic mechanisms (See L15)
	- Size-independent
- Disadvantages
	- Requires knowledge of the shape
	- Difficult for molecules that involve atoms' with shapes that are not tetrahedral, trigonal planar, or linear.
	- Does not represent electronic features that arise from symmetry and delocalisation (See L14)
	- Less accurate for molecular properties/agreement with experiments.
## 3. Trends in bonding
### 3.1. Strength of bonds
- Knowing the trends of bonding can be helpful for selecting the best model when describing the bonding.
- **General rule**: Where two **valence** orbitals of similar energy combine, the **smaller the orbitals the stronger the bond.**
	- The smaller system form a stronger bond due to **greater repulsion between core electrons**.
	- This agrees with the experimental rotational barrier energy values:

| p-p Overlap | Barrier / kJ mol<sup>-1</sup> |
| ----------- | ----------------------------- |
| Si=Si (3p)  | 105                           |
| C=C (2p)    | 274                           |
- So 2p-2p overlap is generally stronger than 3p-2p, which is stronger than 3p-3p.
	- This is one of the reasons why life on Earth is carbon-based; carbon allows for a greater range of π-interactions compared to silicon.
#### 3.1.1. Energy mismatch
- We can see a near-linear increase in energy from B<sub>2</sub> to N<sub>2</sub>, and then a near-linear decreases from N<sub>2</sub> to F<sub>2</sub>.
	- **Strength is positively correlated with bond order.**
- Where there is energy mismatch, there is still a **general positive trend between the bond strength and bond order.**
- **Energy difference leads to polarisation.**

| Atom 1 | Atom 2 | Energy difference / eV | Strength / kJ |
| ------ | ------ | ---------------------- | ------------- |
| N      | N      | 0                      | ~900          |
| C      | O      | 3.4                    | ~1100         |
| B      | F      | 9.6                    | ~700          |
- **Bond strength does not necessarily tell us about the reactivity**.
	- BF is very reactive and is unstable. 
- So just because the strength is relatively high, the molecule can still be quite reactive.
### 3.2. Categorising bonds
- The difference in valence orbital energy (well, electronegativity) is a good indicator of whether a bond (and consequently a molecule) is going to be more covalent or ionic.
	- This is graphically depicted using a **van Arkel-Ketelaar triangle**.
- For the triangle, the difference between valence orbital energy is on the y-axis
	- So highly ionic compounds are at the top, like CsF
	- Highly covalent atoms are at the bottom, like homodiatomics.
### 3.3. Bonding in organic molecules
#### 3.3.1. Molecularorbitals
- When HAOs are considered, it is important to known the HOMO.
- We have a general idea of how the MOs are ordered:

| MOs              |
| ---------------- |
| σ* (antibonding) |
| π* (antibonding) |
| Non-bonding      |
| π (bonding)      |
| σ (bonding)      |
- We might realise that non-bonding is often the HOMO due to lone pairs, and if not, the π is the HOMO.
- We might also realise that antibonding orbitals have more nodes than bonding, so there is an overall increase in number of nodes.

#### 3.3.2. Atomic orbitals:
- We can also order the atomic orbitals (and HAOs) by energy:

| Carbon (H)AOs  |
| -------------- |
| p              |
| sp<sup>3</sup> |
| sp<sup>2</sup> |
| sp             |
| s              |

| Substituent AOs |
| --------------- |
| H               |
| C               |
| N/Cl            |
| O               |
| F               |
- We can also notice that the substituent AOs, when ranked by energy, also depict a ranking of electronegativity.
- We know (from L11) that AOs closer in energy to the MO has more contribution.
