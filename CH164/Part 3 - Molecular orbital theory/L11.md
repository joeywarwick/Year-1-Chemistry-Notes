## 2. MOs form p-orbitals and s-/p-orbitals
- MOs can form between p-orbitals or between s- and p- orbitals if **they are sufficiently close in energy.**
### 2.1. Overlap of p-orbitals
- In a diatomic molecule, the six p-orbitals will overlap to form six MOs
	- Due to **symmetry**, there are only **2 possible overlap combinations that are possible.**
- When the two have different orientations, i.e. one vertical and one horizontal, the **net overlap becomes 0**, and this is known as a **symmetry forbidden** overlap.
- The **symmetry permitted** overlaps are end-on overlap and side overlap, each resulting in a bonding interaction.
- From this we can say that only AOs that have the **correct symmetry** will interact.
#### 2.1.1. End-on overlap
- In-phase (constructive) overlap leads to a **bonding MO**, this has **no rotational nodal planes**, and is therefore labelled with σ. 
	- This means no nodal planes when **rotated around the bond**.
- The <sub>g</sub> refers to the German word *gerader*, which means it is symmetrical with respect to inversion. It has an **inversion centre**.
- Out-of-phase (destructive) overlap leads to an antibonding MO, which also has **no rotational nodal planes**, but a nodal plane at the centre, where the orbitals cancel out exactly.
	- It hence also receives σ.
- The <sub>u</sub> refers to German *ungerader*, hence no inversion centre.
#### 2.1.2. Side-on overlap
- End-on overlap creates MOs with **one** rotational nodal plane, and are therefore labelled with π.
- In-phase creates π<sub>u</sub>, out-of-phase creates π<sub>g</sub><sup>*</sup>.
> **NOTE** that this is **opposite to end-on**, where in-phase is g and out-of-phase is u.
- Side-on overlap leads to a lesser extent of overlap compared to end-on, meaning that the **bond enthalpy for a π bond is less compared to a σ.**
### 2.2. Energetics
- Because of the different in overlap between σ and π, the degree of stabilisation and destabilisation for bonding and antibonding varies.
	- Because of greater extent of overlap, σ-orbitals are more stabilised (and destabilised) relative to the AOs.
- So this creates two pairs of two π-orbitals that have the same energy. These are known as being **doubly degenerate**.
	- The σ-orbital is therefore **singly degenerate**.
### 2.3. MOELD for oxygen
- Oxygen (O<sub>2</sub>) is **paramagnetic**, meaning that it is drawn to magnetic fields due to unpaired electrons.
	- On the Lewis structure of oxygen, there are **no unpaired electrons.**
- So the two 2s orbitals form 1σ<sub>g</sub> and 1σ<sub>u</sub><sup>*</sup>, and the six 2p orbitals form 2σ<sub>g</sub>, 2 x 1π<sub>u</sub>, 2 x 1π<sub>g</sub><sup>*</sup>, and 2σ<sub>u</sub><sup>*</sup> (in order of increasing energy)
	- We do not need to consider the 1s AOs because they do not impact the bonding much overall.
- They will fill up just like AOs:

|                            | Electron 1 | Electron 2 |
| -------------------------- | ---------- | ---------- |
| 1σ<sub>g</sub>             | ✓          | ✓          |
| 1σ<sub>u</sub><sup>*</sup> | ✓          | ✓          |
| 2σ<sub>g</sub>             | ✓          | ✓          |
| 1π<sub>u</sub>             | ✓          | ✓          |
|                            | ✓          | ✓          |
| 1π<sub>g</sub><sup>*</sup> | ✓          |            |
|                            | ✓          |            |
| 2σ<sub>u</sub><sup>*</sup> |            |            |
- The electrons are indeed unpaired in the two 1π<sub>g</sub><sup>*</sup> orbitals to maximise spin (Hund's), proving that oxygen is paramagnetic.
- From this we can calculate the bond order of O<sub>2</sub> to be $\frac{1}{2}(8-4) = 2$. 
#### 2.3.1. HOMO and LUMO
- HOMO stands for **highest occupied molecular orbital**. 
- LUMO stands for **lowest unoccupied molecular orbital.**
- For oxygen, HOMO is 1π<sub>g</sub><sup>*</sup>, and LUMO is 2σ<sub>u</sub><sup>*</sup>.
### 2.4. Interaction between different AOs
- When orbitals with two different energies and/or shapes interact, there is **no longer a inversion centre**, so we **do not use g or u to describe them anymore.**
#### 2.4.1. Energetics
- AOs closer in energy will create larger MO interactions. 
- The closer an AOs energetically to the MO, the more it contributes to the character of the AO.
	- Take two AOs A and B. If they are degenerate (have the same energy), they contribute equally to the MO.
	- If A is higher than B, A will **contribute more to the antibonding MO**, and B will contribute less.
		- Similarly, B will contribute more to the bonding MO and A contributes less.
	- If A is much greater than B energetically, the **contribution of B becomes insignificant** and it appears as if the **antibonding electrons are localised on A.**
		- And also the opposite way around!
	- This is fundamentally **electronegativity**.
		- When two AOs have the **same energy,** the bond is **purely covalent.**
		- When there is **some energy difference**, the bond is **polarised.**
		- When there is a **very large difference**, the bond becomes more **ionic.**
- This arises from **weighted combinations of AOs**.
#### 2.4.2. Weighted combinations of AOs
- To quantify the contribution of an AO to the MO, we use a quantity called molecular orbital coefficient.
- It has the symbol c, so the wavefunction for a MO can be written as: $\psi (MO) = c_A \psi (AO_A) + c_B \psi (AO_B) + \ldots$ 
- If the contribution of A is larger, c<sub>A</sub> becomes larger, so the MO looks more similar to A.
- So this form a continuum.
#### 2.4.3. Non-bonding orbitals
- If there is a **very large energy difference** between an AO and the other orbitals such that it doesn't bond to any other orbitals, the AO will not bond and are therefore **non-bonding** orbitals.
- Take LiH:

| Li  |          | H   |          |
| --- | -------- | --- | -------- |
| 2s  | -5.4 eV  | 1s  | -13.6 eV |
| 1s  | < -50 eV |     |          |
- The 1s on H will interact with the 2s on Li because they are closer in energy than the 1s on Li.
- The 1s on Li will then have no orbitals to bond to.
- So it is **non-bonding**.
- Given this, we can also say that the bonding MO between Li and H will be quite polarised towards H and the antibonding will be polarised towards Li.
	- (Hence very ionic)
### 2.5. Interactions between s- and p-orbitals
- Because we know that s-orbitals are spherical, there are only two overlapping combinations between a s- and a p-orbitals.
- End-on overlap results in an interactions
- Side-on overlap results in net-zero interaction, so it is **symmetry forbidden**.
#### 2.5.1. MOELD for HF
- We can take HF for example:

| H   |          | F                  |          |
| --- | -------- | ------------------ | -------- |
| 1s  | -13.6 eV | 2p<sub>x,y,z</sub> | -18.1 eV |
|     |          | 2s                 | -40.0 eV |
- We can see that 2s is obviously non-bonding, but what about 2p?
	- Only one of the three 2p can form MO with the 1s from hydrogen.
- 2p<sub>z</sub> will form the MO with 1s, because only 2p<sub>z</sub> gives **symmetry-permitted** end-on overlap.
- So this yields the following MOs:

| H   | HF  | H              |             |
| --- | --- | -------------- | ----------- |
| 1s  | 3σ* | 2p<sub>z</sub> | Antibonding |
|     | 1π  | 2p<sub>x</sub> | Non-bonding |
|     | 1π  | 2p<sub>y</sub> | Non-bonding |
| 1s  | 2σ  | 2p<sub>z</sub> | Bonding     |
|     | 1σ  | 2s             | Non-bonding |
- We populate them using 8 electrons (1 from hydrogen, 7 from fluorine):

| MO  | Electron 1 | Electron 2 |
| --- | ---------- | ---------- |
| 3σ* |            |            |
| 1π  | ✓          | ✓          |
| 1π  | ✓          | ✓          |
| 2σ  | ✓          | ✓          |
| 1σ  | ✓          | ✓          |
- We can calculate the bond order, HOMO, and LUMO for this.
	- $Bond \space order = \frac{1}{2}(2-0) = 1$ (**Non-bonding electrons are ignored**)
	- HOMO = 1π
	- LUMO = 3σ*
- We can see that the bonding 2σ orbital would have a **lot of 2p<sub>z</sub> character**, meaning that the bond would be **very polarised towards the fluorine** - exactly what we are expecting.
### 2.6. Interactions between s- and p-orbitals in homodiatomics
- We did not account for potential interactions between s-orbitals and p-orbitals when we worked with O<sub>2</sub>.
- This was not a problem because:
	- The difference in energy between 2s and 2p increases down the second period.
	- At O the difference is 17.5 eV, where the difference is large enough to not produce a significant interaction.
- The reason was that s-orbitals can **penetrate** to the nucleus more effectively, resulting in **higher Z<sub>eff</sub>** (See [[CH164/Part 2 - Quantum mechanics/L9]])
- So Ne<sub>2</sub> does not exist, but F and O both exist in diatomic forms. At **N there is now substantial s-p mixing.**
	- This will require us to consider all combinations between the 4 AOs (2 x 2s and 2 x 2p<sub>z</sub>)
		- This is very complicated.
	- A simpler way is to see how the MOELD is perturbed by s-p mixing.
#### 2.6.1. Perturbation of MOELDs 
- When you have **orbitals of similar symmetry,** they will tend to **push each other away.**

| AOs | LHS             | AOs | Energy Change | RHS             |
| --- | --------------- | --- | ------------- | --------------- |
| 2p  | 2σ<sub>u</sub>* | 2p  | Up            | 2σ<sub>u</sub>* |
| 2p  | 1π<sub>g</sub>* | 2p  | -             | 1π<sub>g</sub>* |
| 2p  | 1π<sub>g</sub>* | 2p  | -             | 1π<sub>g</sub>* |
| 2p  | 1π<sub>u</sub>  | 2p  | -             | 2σ<sub>g</sub>  |
| 2p  | 1π<sub>u</sub>  | 2p  | -             | 1π<sub>u</sub>  |
| 2p  | 2σ<sub>g</sub>  | 2p  | Up            | 1π<sub>u</sub>  |
| 2s  | 1σ<sub>u</sub>* | 2s  | Down          | 1σ<sub>u</sub>* |
| 2s  | 1σ<sub>g</sub>  | 2s  | Down          | 1σ<sub>g</sub>  |
- Because the bonds formed by end-on overlap of 2p and 2s have similar symmetry, they push each other apart.
	- This results in **lowered energy** for the 1σ orbitals and increased energy for the 2σ orbitals.
- There is some **contribution form the other AOs** in the formation of the MOs.
	- A **dotted line** is used to represent this.
- This can be seen as linear combination of MOs.

| MO             | LC of MOs       | MO             |
| -------------- | --------------- | -------------- |
|                | 2σ<sub>u</sub>' |                |
| 2σ<sub>u</sub> |                 |                |
|                | 2σ<sub>g</sub>' |                |
| 2σ<sub>g</sub> |                 |                |
|                |                 | 1σ<sub>u</sub> |
|                | 1σ<sub>u</sub>' |                |
|                |                 | 1σ<sub>g</sub> |
|                | 1σ<sub>g</sub>' |                |
- We can see that there is a increase and decrease in energy respectively.
#### 2.6.2. MOELD of N<sub>2</sub>
- You would expect:

| MO              | Electron 1 | Electron 2 |
| --------------- | ---------- | ---------- |
| 2σ<sub>u</sub>* |            |            |
| 1π<sub>g</sub>* |            |            |
| 1π<sub>g</sub>* |            |            |
| 1π<sub>u</sub>  | ✓          | ✓          |
| 1π<sub>u</sub>  | ✓          | ✓          |
| 2σ<sub>g</sub>  | ✓          | ✓          |
| 1σ<sub>u</sub>* | ✓          | ✓          |
| 1σ<sub>g</sub>  | ✓          | ✓          |
- HOMO = 1π<sub>u</sub>, LUMO = 1π<sub>g</sub>*
- No unpaired electrons, Bond order 3
- But realistically

| MO              | Electron 1 | Electron 2 |
| --------------- | ---------- | ---------- |
| 2σ<sub>u</sub>* |            |            |
| 1π<sub>g</sub>* |            |            |
| 1π<sub>g</sub>* |            |            |
| 2σ<sub>g</sub>  | ✓          | ✓          |
| 1π<sub>u</sub>  | ✓          | ✓          |
| 1π<sub>u</sub>  | ✓          | ✓          |
| 1σ<sub>u</sub>* | ✓          | ✓          |
| 1σ<sub>g</sub>  | ✓          | ✓          |
- HOMO = 2σ<sub>g</sub>, LUMO = 1π<sub>g</sub>*
- No unpaired electrons, Bond order 3
- This make a difference in the electron configurations.
- For nitrogen in particular, the 2σ<sub>g</sub> becomes quite high, so it could become somewhat non-bonding.
