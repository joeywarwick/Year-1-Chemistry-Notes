## 2. Diastereomers
- The number of stereoisomers possible is correlated to the number of stereocentres.
	- $n_{stereoisomers} = 2^x$
		- x is the number of stereocentres
- Stereoisomers that are **not** enantiomers are called diastereomers/diastereoisomers.
	- They are **non-superimposable** and **non-mirror images**.
	- They have different physical/chemical properties so can be separated pretty easily.
- For each stereocentre we assign a configuration individually.
	- We name it as config,config,config...-molecule.
		- e.g. R,S-molecule
> **NOTE** To convert between enantiomers, we invert all stereocentres. To convert between diastereomers, we invert at least one, but **not all** stereocentres. So for a molecule with two stereocentres, R,S and S,R are enantiomers.
### 2.1. Meso- compounds
- A compound with two or more stereocentres but is superimposable on its mirror image is a meso- compound.
	- They have a mirror plane.
- An example is tataric acid.
	- HOOC-CHOH-CHOH-COOH
- Meso- compounds are:
	- **Achiral**
	- They **do not** rotate plane-polarised light.
### 2.2. Conformation and configuration
- Conformations:
	- Are one of the **infinite** arrangements possible which arises from rotation about a single bond. (See L2)
- Configurations:
	- Are arrangements of atoms in a molecule. There are a **finite** number of arrangements and conversion between which can usually only be achieved via breaking bonds.
### 2.3. Achiral diastereomers
- Trans- and cis- alkenes are **non-superimposable** and **non-mirror images**.
	- They are therefore diastereomers without stereocentres.
- They arise from the rotational barrier about double bonds.
#### 2.3.1. E/Z notation
1. Assign priorities like CIP rules
2. If highest priority (P1) on same side then Z, if different E.
> E and Z come from German *entgegen* and *zusammen*. I like to memorise it as Z for 'zame zide'.
- We can also use this for any species with double bonds:
	- imines, oximes, enolates...
#### 2.3.2. Cis/trans and Syn/anti
- Cis/trans can be used where:
	- Restricted rotation is present (double bond, rings)
	- The atoms on either side have at least **one atom** in common.
> It is generally safer to use E/Z.
- Syn/anti is used to describe the arrangement in **conformers** (See L2).
